## Three complete flows

### 1. A full stop. Or a whole story?

**Familiar entry:** you suggest another café. A friend replies “Fine.” No personal story or registration.

**Practice:** a non-graded first reading leads directly to three reversible windows: the words, the first reading, another possible reading. The unchanged canonical mark sits behind the words; the independent reflective layer shifts only when changing view. A person can set a quick-reply reading, an annoyed reading or uncertainty beside the same words. No view is the solution.

**Response:** keep the first reading; leave another beside it; or leave the meaning undecided. Another-reading completion is unavailable until that view is actually visited, with a visible explanation. The initial “I can’t tell” already closes the try; trying the windows after that is an invitation, never a re-ask.

**Closing:** describes only the views actually used and the stance chosen. The visible words remain separate from unknown intent. It does not infer how the friend feels, congratulate a changed perspective or claim a personal capacity improved.

**Optional next step:** open the short mechanism explanation, try a different fictional “Sure.” scene, or leave. Nothing follows automatically.

**Truthful value:** a brief, enacted distinction between a message and the meaning added to it. The same sentence has visibly different readings. Leaving before trying another reading is not a completed comparison. Unknown/early-exit paths claim less; no comparison is claimed if none occurred.

**Status:** mocked local state machine. Existing Look Again pilot has ten acts on user-provided material; silently replacing that runtime with this short fictional exercise would be a behavioral change. It is deliberately not connected to Look Again, engine records, receipts or evidence.

### 2. A little less everywhere.

**Familiar entry:** an optional practice about the visitor’s own attention right now. Choose from the existing fixed list. No typing, personal narrative, persistence or account connection. Skip/unknown/Not now stay available under the actual runtime contract.

**Practice:** real Attend multi-select (max five) → each pull gets exactly one disposition. One foreground choice only; a second Attend-now is disabled with the real runtime reason. Back allows freeing the original choice; it is never reassigned silently. Set-aside asks the real supported time options and explicitly creates no reminder. Leave-open, do-nothing and unknown remain separate.

**Response:** optional self-ended hold, or no hold; actual sit/rearrange steps. Nothing-pulling and unknown on the first step close immediately. There is no countdown or task completion.

**Closing:** derived from the actual record, showing placement count and arrangement. Unknown placements are not described as deliberate no-action. A completed hold only establishes that the person chose its end, not focused attention. The optional detail uses the actual `RepValue.usefulNow` / `unknown` facts with an explicit own-life, in-memory review scope. All-unknown placements explicitly say nothing has been placed.

**Optional next step:** inspect why the arrangement is useful, begin a new optional Attend session, or leave. Carry-forward offers are not connected; no promise of memory is made.

**Truthful value:** the person operates on a set of competing pulls and produces a concrete arrangement. This is materially different from reporting “I kept switching.”

**Status:** `PilotSession('attend') → session.step(): PStep → PAnswer → session.answer() → record()/valueOf()`. Same runtime emits sequence, disables second foreground choice, supports back and allows one rearrangement. In-memory only; `prior:[]`; no store/backup imports, no pilot or engine writes. Fictional choices must never be replayed into personal evidence.

### 3. Before you say yes.

**Familiar entry:** a friend asks for moving help on Saturday. Half an hour is free; afternoon is undecided. An unsent all-day draft is already visible.

**Practice:** actually edit the offer: half an hour, check first, decline, or retain the original. A smaller offer can take an optional authored limit/uncertainty line. Only coherent combinations are generated. The draft changes visibly as it is edited.

**Response:** read the draft beside known free time and unknown afternoon; edit again, keep the draft for the closing, leave it unsent, or choose unknown. No “send” action, obligation or personal relationship question.

**Closing:** an edited artifact and the operation performed, not a motivation. Keeping the original explicitly preserves its unestablished all-day promise; it is not graded or congratulated. Unknown/unsent paths do not claim completed boundary practice. No action is scheduled.

**Optional next step:** read the mechanism explanation, rehearse another wording, or leave. No obligation to use a draft outside the scene.

**Truthful value:** rehearsal of making an offer explicit and examining its size against available time. There is a concrete piece of language to inspect, without advice about a real relationship.

**Status:** mocked authored composer. The frozen engine has choice/timeframe mechanics but no reply-composition exercise. `PStep` does not authorize this composer. New behavioral/schema/receipt contracts would be required; none are added here.

## Comparison and recommendation

These are differences in implemented operations, not measured efficacy or enjoyment.

| | Message | Attention | Reply |
| --- | --- | --- | --- |
| Capacity rehearsed | Separate observable words from possible meaning | Place attention deliberately; keep one foreground | Deliberate response / size of an offer |
| Operation | Switch/compare reversible readings | Allocate a set under a real constraint | Compose, inspect, revise an unsent reply |
| Immediate artifact | Same words with readings kept distinct | Current arrangement with unknowns visible | Authored draft alongside known/unknown time |
| Entry burden | Smallest: one fictional message | Highest: selection and per-item steps | Moderate: familiar scene + editable draft |
| No-action value | Leave meaning unsettled, no forced positive view | Leave open / let be / no foreground / unknown | Withhold a promise or leave draft unsent |
| Runtime readiness | Mocked shorter fictional form | Existing actual Attend session, own-life/in-memory | Mocked new composer |
| Main risk | Could still feel like a comprehension quiz, or mere reading | Eight initial options and repeated steps may feel like admin | Scene implies “half an hour” is the answer; generic scripts can feel prescriptive |
| Research distinction | Can people name the difference between words and interpretation? | Does an arrangement feel useful rather than like tidying a list? | Does editing feel like practice, or finding the socially preferred reply? |

**Recommend Attention as the product foundation to test first**, not an automatic rollout. Its central operation is explicit, its artifact is tangible, and its evidence boundary is already implemented. It gives the strongest answer to “what did you practise?” without relying on a personal inference or a flattering closing. It also carries the biggest first-session friction risk. Test selection and per-pull pacing carefully; do not silently simplify approved runtime sequencing. Any lighter cold-start version belongs in Claude's forthcoming contract.

Use Message as the lower-burden challenger. It may win as an invitation for people uninterested in self-improvement, but that is a hypothesis. Keep Reply as the distinct response-rehearsal alternative; it needs content/mechanics approval and stronger testing against a perceived right answer. Do not merge all three into an obligatory first session or a course.

## Human-study protocol (not started)

Use the reconciled design: 12 adults, two of three prototypes each; six ordered pairs each twice; eight exposures per prototype, four first/four second. Gates are screening, not statistical proof or an efficacy/retention ranking. Founder approval, adviser review of consent/safety, participant access and any thank-you decision remain pending. No invitations or collection are authorized by this preview. The questions below supplement, not replace, Claude’s full protocol.

### Neutral questions

Recruit willing first-time visitors; counterbalance order. Give each person only a direct link and “Try this as you would if you found it on your phone. You can stop whenever you like.” Do not name a capacity, explain the windows or demonstrate a preferred path.

After they stop, ask:

1. “What, if anything, did you do here?”
2. “Was any part useful to you? What made it useful or not useful?”
3. “Did it feel as though there was an answer you were meant to choose?”
4. “Was there anything confusing, effortful or unnecessary?”
5. “Would you willingly try something like this again? Why or why not?”

Record verbatim answers and observed hesitation, including uncertainty/exit paths. Ask clarifying questions only after their unprompted account. Specifically observe whether Message feels graded, Attention feels like task management, or Reply feels like a moral lesson. Automated tests below cannot answer those questions. No human results or preference statistics are claimed.
